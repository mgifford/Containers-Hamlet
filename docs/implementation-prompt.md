# Implementation prompt for another LLM

You are improving an MIT/CC BY 4.0 GitHub Pages starter for a fictional 15-acre Canadian lakeside eco hamlet. Preserve all existing files, licences, disclaimers and accessible HTML fallback. Audit the current prototype and deliver Phase 1.1: a single source of truth for cabin geometry that generates dimensionally consistent SVG plans, elevations and editable 3D geometry; add cutaway and interior exploration in the browser using a lightweight accessible progressive enhancement; include a common lodge concept; add clear model provenance and reuse material passport fields; provide a configurable fictional terrain with wetland and shoreline no-build zones; document off-site fabrication, crane access, low-disturbance foundations, external insulation and moisture/fire reviews, selectively assessed spray foam, solar-friendly green roofs, independent living-wall trellises, and screened porches. Do not present conceptual drawings as engineered or permit-ready. Keep GitHub Pages static, no user tracking, no backend, no proprietary model dependencies. Test keyboard access, focus, reduced motion, small screens, links, licences, and SVG accessibility. Do not silently remove functionality. Document changed files and remaining assumptions.
