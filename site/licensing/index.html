Audit and matrix

What is licensed, and what is changing?

The repository currently mixes MIT, CC BY 4.0, AGPL-3.0-or-later and CC BY-SA 4.0. This page records the existing position and the intended policy for new original work. It does not relicense existing contributions.

No automatic relicensing. Changing a repository licence requires the rights-holders' permission and a review of third-party material. Existing files keep their current notices until that review is complete.
