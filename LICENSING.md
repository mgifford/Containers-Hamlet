# Licensing matrix

This repository currently contains material under more than one licence. This file records the position and the intended policy for new original work. It does **not** relicense existing contributions.

| Material | Current licence | Intended for new original work |
| --- | --- | --- |
| Core application code (`tools/`, `site/js/`, `site/script.js`, HTML/CSS) | MIT (`LICENSE`) | AGPL-3.0-or-later, subject to contributor review |
| Core original text, site illustration, SVG drawings, OBJ geometry, data | CC BY 4.0 (`CONTENT-LICENSE.md`) | CC BY-SA 4.0 for new original work, subject to review |
| Design Lab code (`site/design-lab/`, `site/js/design-*.js`, adapter) | AGPL-3.0-or-later (`site/design-lab/LICENSE.txt`) | AGPL-3.0-or-later |
| Design Lab documentation, diagrams, concept data, generated views | CC BY-SA 4.0 (`site/design-lab/CONTENT-LICENSE.md`) | CC BY-SA 4.0 |
| Phase 1.5 resident guides, scenarios, ownership/cost/roadmap/living text | New original work | CC BY-SA 4.0 |
| Phase 1.5 original diagrams and new arrangement images | New original work | CC BY-SA 4.0 |
| Third-party plans, photographs, product designs, supplier images | Not bundled unless separately cleared | Retain original notices; do not relicense |

## Why not simply replace MIT and CC BY 4.0?

Relicensing needs the rights-holders' permission and a review of every third-party contribution/asset. The repository contains historical contributions and references whose rights have not all been re-confirmed. Phase 1.5 therefore adds a clear matrix, applies the intended licences to **new original work**, and leaves existing notices intact.

## Attribution

Original work: Containers Hamlet contributors. Design Lab code: AGPL-3.0-or-later. Design Lab concept data/diagrams and Phase 1.5 resident guides: CC BY-SA 4.0. Core architectural models/text remain under their existing MIT/CC BY 4.0 notices until a rights review says otherwise.

## Third-party material

No third-party plans or photographs are bundled unless the repository records confirmed redistribution rights. Supplier links and references are not endorsements or licences. Do not upload an image, plan or product design unless you can document the right to redistribute it.

See `docs/phase-1.5-audit.md` for the audit and `site/licensing/index.html` for the public matrix.
